# The Comfy Oak Tree – Screenshot Matched + Expanded Image Pack

This version keeps the previous responsive Hobbit/tree-home design and adds the additional image assets supplied for the site.

## GitHub Pages
Put all files in the repository root. The HTML uses relative image paths such as `tree-door.png`, `23.jpg`, and `lantern-illustration.jpg`.

The site is designed to adapt across Android, iPhone/iPad, Windows, macOS, and Linux browsers.
